📘 About Project

This project is a simulation of memory management in Operating Systems. It demonstrates how pages are loaded into memory and replaced using different algorithms.

🧠 OS Concepts Used

  • Memory Management
  • Paging
  • Page Replacement Algorithm
  • FIFO (First In First Out)
  • LRU (Least Recently Used)
  • Page Fault
  • Frame Allocatin
  • Algorithm Simulation
  • Performance Analysis
  • Interactive Prediction System
