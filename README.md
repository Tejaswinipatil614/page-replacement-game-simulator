# Page Replacement Game Simulator

An interactive web-based game that makes Operating Systems page replacement algorithms easier to understand through simulation and visualization. Players process page references, manage memory frames, and aim to minimize page faults.

## 🚀 Features

- Interactive game-based learning experience
- Page reference sequence simulation
- Real-time memory frame visualization
- Page hit and page fault tracking
- Step-by-step page replacement
- Score-based gameplay

## 🧠 Algorithms

- **FIFO (First-In, First-Out)**
- **LRU (Least Recently Used)**

## 🛠️ Technologies

- HTML
- CSS
- JavaScript

## 🎯 Objective

To combine learning and gameplay to provide an engaging way to understand memory management and page replacement concepts.
